## Roteiro de um primeiro componente

Esta área ainda não contém aplicação Vue nem dependências instaláveis.
Antes de criar um exemplo, pratique funções, arrays, objetos e promessas
em JavaScript. Documente as versões e os comandos no README do exemplo.

Para um exercício de lista de tarefas:

1. Receba os itens por props e use uma chave estável para cada item renderizado.
2. Emita um evento ao concluir uma tarefa, deixando a atualização dos dados com o componente responsável.
3. Verifique lista vazia, um item e vários itens antes de acrescentar uma API.
4. Ao adicionar carregamento remoto, represente os estados de carregamento, sucesso e erro.
5. Teste uma falha de rede e ofereça uma ação de tentar novamente.

Introduza um composable quando houver lógica reaproveitável e Pinia quando
houver estado compartilhado que justifique uma store. Não é necessário usar
todos os tópicos do checklist no primeiro exercício.
