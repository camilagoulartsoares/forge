# Acompanhamento com Suporte

## Objetivo

Estudar o acompanhamento com suporte sem registrar dados internos ou pessoais.

## Conceitos abordados

- Fluxo do sistema
- Particularidades documentadas de forma segura

## Pré-requisitos

Nenhum.

## Como executar

Registre apenas conteúdo autorizado.

## Exemplos

Use um relato reproduzível com dados inteiramente fictícios:

| Campo | Exemplo educacional |
| --- | --- |
| Contexto | Formulário local de cadastro de um exercício |
| Passos | Abrir formulário, deixar nome vazio e enviar |
| Resultado esperado | Exibir mensagem de campo obrigatório |
| Resultado observado | Envio aceito sem mensagem |
| Frequência | Ocorre em três tentativas com a mesma entrada |
| Impacto | Exercício permite criar registro incompleto |
| Próxima verificação | Conferir validação no formulário e no backend |

Separe o que foi observado da hipótese sobre a causa. Não copie tickets,
logs ou capturas de sistemas reais; trocar apenas o nome de uma pessoa não
garante a remoção de dados internos. Reproduza o comportamento em um exemplo local.
