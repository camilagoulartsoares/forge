# Eventos do Scrum

O Scrum Guide descreve a Sprint como o evento que contém os demais.
Use o quadro para distinguir seus propósitos durante o estudo:

| Evento | Foco |
| --- | --- |
| Sprint | Trabalhar em direção a uma meta e produzir valor |
| Sprint Planning | Definir por que a Sprint é valiosa, o que fazer e como começar |
| Daily Scrum | Inspecionar o progresso em direção à meta e adaptar o plano |
| Sprint Review | Inspecionar o resultado com stakeholders e discutir adaptações |
| Sprint Retrospective | Planejar melhorias de qualidade e eficácia do trabalho |

A Review não é apenas uma apresentação e a Daily não é uma prestação de
contas a um gerente. O refinamento do backlog é uma atividade contínua,
não um evento formal adicional definido pelo guia.

## Exercício de observação

Em uma simulação com dados fictícios, registre qual decisão cada evento
permitiu tomar. Compare os resultados com o propósito correspondente e
proponha um ajuste quando uma reunião não produzir uma adaptação útil.

Referência: [Scrum Guide 2020](https://scrumguides.org/scrum-guide.html).
