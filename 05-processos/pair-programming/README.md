# Pair Programming

## Objetivo

Registrar práticas, aprendizados e dúvidas sobre programação em dupla.

## Conceitos abordados

- Driver e navigator
- Comunicação técnica

## Pré-requisitos

Nenhum.

## Como executar

1. Definam um objetivo observável, como corrigir um caso de erro de um exercício.
2. Confirmem o estado do Git e preservem as mudanças que já existiam.
3. Combinem quem será driver (digita) e navigator (acompanha e questiona).
4. Escolham um intervalo para trocar de papel e reavaliem o objetivo na troca.
5. Executem a verificação combinada e revisem o diff juntos.
6. Registrem o resultado, as dúvidas e o próximo passo antes de encerrar.

O navigator deve acompanhar a regra e os casos de erro, enquanto o driver
explica as decisões durante a implementação. Se surgir uma investigação
fora do objetivo, anotem para outra sessão ou redefinam o escopo explicitamente.
