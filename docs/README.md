# Documentação

Esta pasta reúne anotações gerais, referências, boas práticas, cheatsheets e imagens usadas na documentação.

Para documentar um novo exercício ou exemplo, use o [modelo de estudo](modelo-de-estudo.md),
com campos para execução, resultados esperados e verificações.

Antes de publicar, execute o [verificador de documentação](../tools/README.md)
para detectar links locais quebrados e blocos de código não fechados.
