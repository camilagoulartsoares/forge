# Onboarding

Esta pasta reúne materiais de boas-vindas, visão geral da empresa, preparação do ambiente e conhecimentos iniciais do onboarding. Registre apenas informações autorizadas e de uso educacional.

## Por onde começar

1. Leia as [boas-vindas](boas-vindas/README.md) e registre suas dúvidas iniciais.
2. Confira o [ambiente local](ambiente/README.md) para o tema que pretende estudar.
3. Siga para os [fundamentos](../01-fundamentos/README.md), antes de avançar aos frameworks.
4. Use o [modelo de estudo](../docs/modelo-de-estudo.md) para registrar execução e resultados.

Mantenha os tópicos em aberto até conseguir explicar os conceitos e repetir
as verificações do estudo. Não registre como aprendizado uma atividade ainda
não realizada; anote o impedimento e o próximo passo.
