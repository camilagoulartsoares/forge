# Checklist de Merge Request

- [ ] Descrever o problema, o objetivo e o comportamento esperado após a mudança.
- [ ] Confirmar a branch de destino e revisar todos os arquivos do diff.
- [ ] Manter o escopo focado, sem alterações não relacionadas ou arquivos gerados.
- [ ] Conferir se os commits têm mensagens específicas e coerentes com as mudanças.
- [ ] Informar os comandos de verificação executados e seus resultados; quando não houver testes aplicáveis, explicar o motivo.
- [ ] Verificar casos de erro e limites quando houver mudança de comportamento.
- [ ] Atualizar instruções de execução, exemplos e links afetados.
- [ ] Conferir que o diff não inclui credenciais, dados pessoais ou materiais internos.
- [ ] Registrar limitações conhecidas e pontos que precisam de atenção do revisor.

Marque somente os itens verificados. Para um item que não se aplica, registre
o motivo na descrição do Merge Request em vez de indicar uma verificação inexistente.
