# Fundamentos

Reúne fundamentos de PHP, MySQL, Git, orientação a objetos, testes automatizados e padrões de escrita.

## Sequência sugerida

| Estudo | Conhecimento necessário | Resultado da prática |
| --- | --- | --- |
| [Fluxo Git](git/fluxo-de-trabalho/README.md) | Terminal e arquivos | Revisar um diff e preparar um commit coerente |
| [Introdução ao PHP](php/introducao/README.md) | Lógica básica | Executar um programa com tipos e controle de fluxo |
| [POO](php/poo/README.md) | Funções e tipos em PHP | Encapsular uma regra em uma classe |
| [MySQL](mysql/introducao/README.md) | Tabelas e relações | Consultar dados com filtro e ordenação |
| [Testes](php/testes-automatizados/README.md) | Funções e classes | Verificar comportamento normal e casos de erro |
| [Padrões de escrita](php/padroes-de-escrita/README.md) | Leitura de PHP | Melhorar legibilidade preservando comportamento |

MySQL pode ser estudado em paralelo ao PHP. Antes de Symfony, pratique POO
e testes; antes de enviar contribuições, consulte o [checklist de revisão](git/merge-requests/checklist.md).
