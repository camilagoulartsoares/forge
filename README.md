# Forge

O **Forge** é uma base pessoal de estudos, anotações, exercícios e experimentos técnicos desenvolvidos durante a trilha de onboarding.

O nome “Forge”, que significa “forja”, representa um ambiente onde conhecimentos são construídos, testados e aprimorados continuamente.

## Objetivo

Centralizar estudos técnicos, anotações, exercícios, exemplos de código, provas de conceito, desafios, boas práticas, padrões de desenvolvimento, documentação útil e aprendizados do onboarding. Os conteúdos têm finalidade educacional e não devem ser considerados prontos para produção sem revisão técnica.

> Segurança: este repositório não deve receber materiais confidenciais, código interno, nomes de clientes, URLs internas, tokens, senhas, credenciais, dados pessoais, prints de sistemas internos ou documentos não autorizados.

## Tecnologias e temas

**Backend:** PHP, Symfony, MySQL, Doctrine, PHPUnit e APIs REST.

**Frontend:** JavaScript, TypeScript, Vue.js, Vue Router, Pinia e Vitest.
**Engenharia:** Arquitetura Hexagonal, Clean Architecture, Design Patterns, Git, testes automatizados, PSR-12, Code Review, Merge Requests, Pair Programming e Scrum.

## Estrutura

- `00-onboarding`: boas-vindas, ambiente e materiais iniciais.
- `01-fundamentos`: PHP, MySQL, Git, testes e padrões de escrita.

